NextC

一门受 C 语言启发，兼具现代语法、更强类型安全、极致性能和完全底层控制权的系统编程语言。

核心哲学

  • 严格的类型安全：数组和指针分离、不允许隐式类型转换、不允许指针与其它类型的转换、严格常量（const）。
  • 安全的指针操作：不允许指针算术、不允许数组指针、运行时空指针检查（Debug 模式）。
  • 自由的内存管理：可选择与 C 一样的手动内存管理，或者使用计划在 2.0 版本引入的 GC（将禁用手动释放内存的 delete 语句）。
  • 运行时检查未定义行为：在 Debug 模式下，可以检查数组越界、union 的正确性等。
  • 高效而精简：借鉴 C 的简洁性与高性能，将源代码直接编译为 LLVM IR，并由 LLVM 做更多优化。
  • 现代化的语法：使用更现代化的语法，如自动类型推导、固定长度整数类型、强制花括号、多遍编译。
  • 模块化编程：可以使用模块进行多文件编程。
  • 与 C 语言连接：支持 C FFI，可以使用外部 C 函数等。
  • 兼容危险底层操作：使用 unsafe 来进行不得不的危险底层操作，如指针运算、数组指针等。

编译器

NextC 编译器使用 Rust 开发前端、LLVM 作为后端。Rust 的第三方库 Inkwell 提供 LLVM 的 Rust 接口。

NextC 编译器将源代码经过词法分析、语法解析转换为 AST；然后在 AST 上进行语义分析，生成修饰后的 AST；随后由代码生成模块将其翻译为 LLVM IR，并交由 LLVM 后端进行进一步的优化和翻译。
